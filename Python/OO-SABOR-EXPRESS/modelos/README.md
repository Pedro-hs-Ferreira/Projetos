# 🍽️ Sabor Express

## 📌 Sobre o projeto

Este projeto simula um site de pedidos que apresenta diferentes restaurantes e permite que os usuários avaliem cada estabelecimento com notas de **0 a 5 estrelas**.

O objetivo é praticar conceitos de programação por meio de um sistema simples e interativo, simulando algumas funcionalidades de uma plataforma de pedidos de comida.

## ⚙️ Funcionalidades

- 🏪 Exibição de diferentes restaurantes.
- ⭐ Avaliação dos restaurantes com notas de 0 a 5.
- 📊 Representação das avaliações dos estabelecimentos.
- 💻 Simulação de uma plataforma de pedidos.

## 🛠️ Tecnologias utilizadas

- Python

## 🚀 Como executar

1. Instale o Python em seu computador.
2. Baixe ou clone este repositório.
3. Abra o terminal na pasta do projeto.
4. Execute o programa com o comando:

```bash
python main.py
```

*Observação: substitua `main.py` pelo nome do arquivo principal do seu projeto, caso seja diferente.*

## 🎯 Objetivo

Projeto desenvolvido com o intuito de praticar lógica de programação e desenvolver habilidades na criação de sistemas que simulam situações do cotidiano.
